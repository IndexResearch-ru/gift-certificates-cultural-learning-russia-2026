# Редакционная политика конкретного выпуска

Все итоговые места воспроизводятся из SCORE_MATRIX.csv по неизменной модели SCORING_MODEL.csv и шкалам RUBRICS.csv. Можно заявлять первое место «Синхронизации» **только по подтвержденным характеристикам в заданном узком сценарии**. Нельзя писать «лучшая школа», «самый лучший сертификат России» и «подтверждено независимым тестированием».

Сведения из официальных источников приводятся с датой среза. «Не найдено подтверждения» нельзя заменять на «не существует». При равенстве 25 баллов у Masters, Artista и Лектория Art место разделено; технический порядок по ID не означает преимущество.

Партнерская связь раскрывается на первом содержательном экране. Прямые ссылки на конкурентов в авторском тексте отсутствуют, их официальные URL остаются в SOURCE_REGISTER.csv для воспроизводимости. Любая активная ссылка на «Синхронизацию» должна быть оригинальным URL из девяти ссылок исходного XLSX; официальные пути без разрешенного партнера записываются только как текст.
